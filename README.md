# ss

Система, в которой у компании есть агент: он ведёт её работу, а из результатов
публикуются миниаппы.

## Как устроено

- **`packages/types`** — правила предметной области и общие типы: события чата и
  комнаты, задачи очереди, результат работы. Чистые функции, без сети и базы.
- **`packages/db`** — схемы таблиц ядра (компании, люди, чаты, сессии агентов),
  клиент базы, настройка миграций, короткие ключи с префиксом.
- **`packages/log`** — журнал: строки с префиксами и след шага в одном пакете.
- **`packages/companies`** — правила компании и вызовы модели: шаги онбординга,
  название чата.
- **`packages/ui`** — общие части интерфейса.
- **`apps/api`** — приложение на Hono: вход, комнаты живого потока, вопросы
  агенту, данные для панели.
- **`apps/web`** — панель на React Router: вход, компания, чат, онбординг.

Подробности: `docs/architecture.md`, план на первый выпуск: `docs/mvp.md`.

## Как запустить

Нужны Bun и Docker (для базы).

```bash
scripts/iso-setup.sh <имя сессии>   # отдельная копия проекта + база
```

Скрипт создаёт копию в `.worktrees/<имя>`, делает в ней `.env` из `.env.example`
и поднимает базу Postgres на порту 5433. Дальше — в копии:

```bash
bun install
bun run db:migrate     # таблицы
bun run dev            # api и web
```

Проверка: `curl localhost:8787/health`.

## Настройки

Секретов в репозитории нет. Образец окружения — `.env.example`; рабочий файл
создаёт скрипт изоляции, и в git он не попадает.
