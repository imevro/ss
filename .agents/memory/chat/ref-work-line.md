# Строка хода работы

Одна строка на ход агента, в ленте над ответом.

```
Working for 29s • bash ×2 • read ×2 • Thinking…       ход идёт
Worked for 29s • bash ×2 • read ×2 • 4 thoughts       ход кончился
```

Правила:

- Слова строки английские (`Working for`, `Thinking…`, `1 thought`/`N thoughts`).
  Это язык агента, не наш интерфейс: остальной текст на странице русский.
- Счёт по **имени** за весь ход: `Bash ×2`, где бы вызовы ни стояли. Один вызов —
  без числа.
- Имя читается как слова: первая буква большая, подчёркивания — пробелами
  (`web_search` → «Web search»).
- В строке не больше двух прошлых инструментов плюс работающий. Ход длинный —
  старое уходит: строка не растёт.
- Идущий сейчас инструмент показывает свой замысел (`intent`), а не имя:
  `Reading in the web about …`.
- «Думает» — состояние без инструмента: мерцающая надпись `Thinking…`.
- Число мыслей считает сведение журнала по кадрам `thought`, строка сама не считает.
- Строка стоит у ответа **агента**, слева, и над его текстом. У вопроса человека
  строки нет: строка — про работу агента.
- Ход кончился — строка берётся **из записи ответа**, не из журнала браузера.
  Поэтому она приходит с серверным рендерингом и не мигает при обновлении.
  Живёт она в сыром поле записи (`raw`), ключ `work`: `seconds`, `names`, `thoughts`.
- Идёт ход — строка живая, из журнала. Куски наполняют ту же реплику агента:
  реплика заводится кадром `started`, а не первым куском.
- Список имён пишется в запись последним кадром хода: каждый кадр заменяет прошлый.
