# Предмет «чат на странице»

Как панель собирает ленту и ход работы из событий.

- [`how-lenta-sobiraetsya-pereigryvaniem`](how-lenta-sobiraetsya-pereigryvaniem.md) — лента и строка работы выводятся из журнала событий, а не хранятся.
- [`ref-work-line`](ref-work-line.md) — вид строки хода работы.
- [`how-nazvanie-chata-rozhdaetsya`](how-nazvanie-chata-rozhdaetsya.md) — название чата придумывает модель по первому вопросу и оно приходит в панель.
- [`how-vopros-zhdyot-ocheredi-a-pustoy-enter-puskaet-verhniy`](how-vopros-zhdyot-ocheredi-a-pustoy-enter-puskaet-verhniy.md) — вопрос поверх идущего хода ждёт в очереди панели, пустой Enter пускает верхний сейчас.
- [`gotcha-pervyy-kadr-ne-chitaet-nastroyku-dvizheniya`](gotcha-pervyy-kadr-ne-chitaet-nastroyku-dvizheniya.md) — настройку «меньше движения» читает эффект, а не первый кадр: иначе разметка разойдётся.
