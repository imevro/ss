# Отрезок адреса один: `sessions` — и для чатов, и для миниаппов

Чат компании и миниапп открываются **одним отрезком адреса**: `/:слаг/sessions/:номер`.
Второго отрезка для миниаппов нет и заводить его не надо: что открыто, решает номер,
а не вид записи (`openIdOf` в `apps/web/app/routes/[company]/sessions/[session]/page.tsx:76-79`).

Правило держится двумя местами, оба в вебе:

- адрес собирается только в `apps/web/app/lib/address.ts` — `companyAddress` печатает
  `/${slug}/sessions`, `sessionAddress` дописывает короткий номер; в разметке адрес
  руками не собирается;
- `apps/web/app/routes.test.ts` сверяет отрезки собирателя адресов со строками
  таблицы адресов: переименуют отрезок в одном месте — проверка упадёт.

Строка таблицы, с которой сверяются отрезки: `apps/web/app/routes.ts:10`.
