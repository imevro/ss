# Обязательный вопрос шага обязателен и в API

Вопрос с `required: true` (`packages/companies/src/steps.ts:57`) обязан быть обязательным
и на входе API, иначе `POST /v1/companies` заводит компанию без ответа. Браузер обходят
запросом или скриптом, а пустое «чем занимается» уезжает в `organization.metadata` и
чинится только правкой данных.

Сделано в `newCompanyOf` (`apps/api/src/onboarding.ts:200-209`): отказ на пустом названии
и пустом описании. Тело описано в `companyBodySchema` (`contracts.ts:140`), шаг — в
`steps.ts:57`.

**Проверка — живыми запросами:** `POST /v1/companies` с одним названием → `400`
(«нужны название и описание компании», `onboarding.ts:120`); с описанием → `201`.
