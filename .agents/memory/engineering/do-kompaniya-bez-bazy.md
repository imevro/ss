# Компания — это название, люди и сессии джентиков

У компании нет своей базы. Компания — запись в общей базе: название, люди с
ролями, приглашения, сессии джентиков. Переписка чатов лежит рядом, в общей базе
(`conversations`/`messages`, `packages/db/src/conversations.ts`).

Выписка баз удалена целиком: маршрут `/v1/companies/:id/database`, задача
`db:provision`, воркер, брокер очереди, реестр `company_databases`, схема `ctx` в
отдельной базе. Всё, что делают с данными компании, делают джентики.

Отсюда следует:

- онбординг — три вопроса и кнопка: название, чем занимается, приглашения;
- своей базы у компании нет, значит и ждать её готовности негде;
- чаты и лента читаются из общей базы одним запросом без обхода компаний;
- доступ к комнате чата проверяется соединением с `member`, а не перебором баз.

**Проверка:** `bun run db:migrate` на чистой базе даёт 14 таблиц без
`company_databases`; заведение компании вторым заходом не упирается в занятый
адрес (`freeSlug` в `apps/api/src/companies.ts`).
