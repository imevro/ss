# Строка агента идёт кадром `log`, а не `failed`

Причина отказа из потока ошибок агента доходит до человека своим кадром `log` (поле
`line`). `failed` для этого не годится: он закрывает ход, снимает строку работы и обрывает
приём кусков ответа.

Путь: комната → `ClientEvent` → `ChatEvent` → сведение → тихая строка под лентой.
Вид кадра — `apps/api/src/contracts.ts:107-111`, `packages/types/src/rooms.ts:38`.
Чтение — `apps/web/app/lib/live.ts:30-33`; перевод — `page.tsx:505` в
`[company]/sessions/[session]`; сведение в `note` — `apps/web/app/lib/chat-state.ts:234`;
показ — `page.tsx:414`; снятие — новый вопрос, `chat-state.ts:196`.

**Проверка:** `chat-state.test.ts:348-355` — после `log` строка видна, после `ask` пуста;
в живом ходе замечание не гасит текст ответа.
