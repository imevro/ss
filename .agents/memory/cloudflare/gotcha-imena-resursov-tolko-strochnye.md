# Имена ресурсов у Cloudflare только строчные

Номер компании — префиксный наноид со смешанным регистром (`comp_o1jpI99oJpSVVR5`). Если имя воркера
строить прямо из него (`comp-o1jpI99oJpSVVR5-bot-demo`), платформа отвечает `400`, код `10016`:
«Invalid Worker name. Ensure the name is lowercase, alphanumeric…». Воркер не заводится, и по ошибке
кажется, что виноват фильтр прокси.

Поэтому начало имени компании приводится к нижнему регистру **в одном месте** — там, где выводится
начало имени (`apps/api/src/cloudflare.ts`, `<номер компании>.replace('_','-').toLowerCase()`), — и
правило проговаривается кланкеру в описании маршрута и в `/openapi`.

- Фильтр по имени и правило для кланкера обязаны брать регистр из одного выражения, иначе своё имя
  перестанет подходить.
- То же у D1: имена баз строчные.
