# Снятый секрет остаётся в версии машины Fly

`fly secrets unset` убирает секрет из списка, но не из версии уже созданной машины: в её
окружении остаётся старое значение, и приложение читает его дальше. Убирает его только
уничтожение машины и создание новой. `machine update --env` задаёт переменную версии, но
старую не убирает.

Опасность: отозванный ключ считают отозванным, а процесс живёт со старой строкой.

**Проверка** внутри машины, не в списке секретов:

```sh
fly ssh console -a <приложение> -C printenv | grep -c '^ИМЯ_СЕКРЕТА='
```

`0` — секрета нет; строка есть — версия машины его держит. Порядок очистки:
`fly machine destroy`, затем `fly deploy`.
