# Один ключ бота — один вебхук: на борд без чатов ключ не кладут

У ключа Telegram-бота ровно один вебхук. Новый адрес **снимает прошлый** без ошибки.
Поэтому борд комнат живёт без ключа бота: скрипт выкладки ставит вебхук на каждом
запуске и тихо уводит обновления у архивного воркера на Cloudflare.

Опасность в том, что никто не падает: бот просто молчит в архиве, а на борде
сообщения никто не читает. Причину ищут в боте, а она в последней выкладке.

- ключ бота стоит только на машине, которая ведёт чаты;
- постановка вебхука — отдельный шаг выпуска бота, не каждая выкладка.

**Проверка:** `getWebhookInfo` до и после выкладки — адрес тот же
(`https://tg.<зона>/b/<бот>`, `docs/bot-on-cloudflare.md:120`). Сменился — обновления
увели.
