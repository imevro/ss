# dostup-k-repo-mic-na-borde-gentic

Борд gentic может сам поставить себе наборы навыков из закрытого репозитория `mic`,
но только когда на нём есть три вещи. Без них установщик падает, а агент говорит
человеку, что «программы больше нет».

1. **Подмена адреса git.** Установщик делает свой `git clone` по открытому адресу и
   среды не читает. Ключ поэтому живёт в настройках git как замена адреса:
   `url.https://x-access-token:<ключ>@github.com/meteredintelligence/.insteadOf`.
2. **Ключ репозитория.** Тонкий ключ `meteredintelligence/mic`, только чтение кода.
   Лежит в настройках борда (`MIC_GIT_TOKEN`) и в `/data/.gitconfig`.
3. **Ключ хранилища пакетов.** Сама программа лежит в закрытом хранилище; нужен
   старый вид ключа с одним правом «читать пакеты», прописанный в `/data/.npmrc`.

Ключ доступа к службе (`mic auth --name <борд>`) борд выдаёт себе сам: человека для
этого не нужно.

Порядок: настройки борда взять в работу (`fly machine update … --env MIC_GIT_TOKEN=…`),
затем подмена адреса, ключ хранилища, установка навыков и выдача ключа службы.

Проверка — настоящая команда установки на борде: в списке навыков должны появиться
`search`, `scrape`, `ocr`, `speech-to-text`, а поиск должен вернуть результат.
